# My Personal Website

This is my personal website. I took a web development class in 9th grade and decided to build a personal site now. I recently joined Hack Club, though, and one of their events going on was Pixl, and so, as a first project, I created this website so that I can keep track of the projects I complete

## Description

My personal website is a project I brought to life to show people the things I've created/done! I am a sophomore in High School, and I love programming and learning new things. I wanted to capture all of my learning experiences on this website I made for Pixl!
